# Contributing to Maximum Entropy Network Reconstruction

Thank you for your interest in this project!

## Archive Status

This repository contains **archived research code** from a published academic paper. The code represents the implementation used in:

> Di Gangi, D., Lillo, F., & Pirino, D. (2018). *Assessing systemic risk due to fire sales spillover through maximum entropy network reconstruction.* Journal of Economic Dynamics and Control, 94, 301-319.

## Contribution Guidelines

While this project is not actively maintained, contributions are still welcome in the following categories:

### Encouraged Contributions

- **Bug fixes**: Corrections to errors that affect functionality
- **Documentation improvements**: Clarifications, examples, or corrections to documentation
- **Compatibility updates**: Adaptations for newer MATLAB versions
- **Performance optimizations**: Improvements that don't change results
- **Test cases**: Additional validation or test scripts

### Guidelines for Contributions

1. **Preserve research integrity**: Do not change algorithms or implementations in ways that would affect published results
2. **Add, don't modify**: When improving functionality, prefer adding new options rather than changing existing behavior
3. **Document changes**: Clearly explain what changed and why
4. **Test thoroughly**: Ensure changes don't break existing functionality

### How to Contribute

1. **Fork** the repository
2. **Create a branch** for your changes
3. **Make your changes** following the guidelines above
4. **Test** your changes with existing examples
5. **Submit a pull request** with:
   - Clear description of changes
   - Justification for the contribution
   - Any relevant testing results

## Reporting Issues

If you find bugs or have questions:

1. Check existing issues first
2. Provide a minimal reproducible example
3. Include MATLAB version and system information
4. Describe expected vs. actual behavior

## Research Use

If you use this code in your research:

1. Please cite the original paper (see README.md)
2. Consider sharing your use case in the issues - it helps demonstrate impact
3. For substantial extensions, consider publishing your own work and linking back

## Code of Conduct

- Be respectful and constructive
- Focus on the technical merits of contributions
- Acknowledge that this is archived academic code
- Help others who are learning from this implementation

## Questions?

For research-related questions about the methods, refer to:
- The published paper
- The technical documentation in `readme.pdf`
- Open an issue for clarification

Thank you for helping preserve and improve this research software!
